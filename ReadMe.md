# Controle de Estoque em Python

Projeto simples de controle de estoque feito em Python para praticar lógica de programação.

# Utilizações
- if / elif / else 
- while 
- dicionários 
- for 
- input 
- .strip()
- upper()
- leitura e escrita em arquivo 
- try/except 

## Funcionalidades

- Adicionar produtos ao estoque
- Remover produtos
- Listar produtos cadastrados
- Remover produtos automaticamente quando a quantidade chega a 0
- Tratamento de entrada do usuário (maiúsculas/minúsculas e espaços)
- Salvamento do estoque em arquivo

## Tecnologias utilizadas

- Python
- Estrutura de dados (dicionário)
- Manipulação de arquivos
